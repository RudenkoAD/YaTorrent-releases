# Корзины AIM2

Сначала прочитай [подключение и клиент](../aim2-api/SKILL.md).

1. Преобразуй исходный список в массив объектов со строковым `text`. Сохраняй
   порядок, повторяющиеся запросы и все предоставленные поля. Не добавляй регион,
   устройство, labels или другие значения без основания в задаче. Labels, если
   указаны, должны быть массивом строк. JSON должен быть конечным, без NaN/Infinity.
2. Найди подходящую корзину через `GET /baskets/catalog?limit=100&offset=0`.
   Это лёгкий список id/name; содержимое читай через `GET /baskets/{id}`.
   Совпадение имени не означает совпадение содержимого.
3. Для создания отправь `POST /baskets` с полным объектом:

```json
{
  "name": "Запросы для сравнения",
  "content": [
    {"text": "пример запроса", "region": 213, "device": "DESKTOP", "labels": ["sample"]},
    {"text": "другой запрос"}
  ]
}
```

Это пример формы, не универсальные настройки региона/устройства. Имя после
trim должно содержать 1–255 символов. Создание не запускает сбор.

Для импорта готового массива существует `POST /baskets/import?name=<URL-encoded-name>`;
тело — сырой массив, без `content`. У create/import нет ключа идемпотентности:
при неопределённом ответе проверь каталог и точное содержимое кандидатов перед
повторной записью; если однозначность не установлена, сообщи это пользователю.

Для изменения сначала прочитай корзину, затем `PUT /baskets/{id}`:

```json
{"name": "Новое имя", "content": [{"text": "пример запроса"}], "expected_revision_id": 3}
```

Передай фактическую последнюю ревизию. PUT заменяет имя и весь массив; это не
добавление одной строки. Любой успешный PUT увеличивает `revision_id`, даже если
данные те же. При 409 перечитай и согласуй изменения, не убирай проверку ревизии.
При потерянном ответе сравни актуальное содержимое, прежде чем повторять PUT.

После создания/изменения проверь через GET имя, ревизию, число строк и точное
содержимое, включая порядок, дубли и метаданные. Не выводи всю большую корзину
в чат. Сообщи ID, revision_id и число запросов.

| Действие | GET |
| --- | --- |
| История снимков | `/baskets/{id}/revisions` |
| Конкретный снимок | `/baskets/{id}/revisions/{revision_id}` |
| Текущий массив в файл | `/baskets/{id}/export` |
| Массив выбранной ревизии | `/baskets/{id}/export?revision=3` |

Экспорт возвращает JSON-массив запросов. Сохраняй через клиент с `--output`.
Изменение корзины влияет на следующие запуски связанных экспериментов/кронов;
прошлые запуски используют замороженную ревизию. Если пользователь хочет
независимый набор, создай отдельную корзину.
